# 🚀 スペースインベーダーゲーム

昔ながらのアーケードゲーム「スペースインベーダー」のクローンです。

## 🎮 ゲームの特徴

- クラシックなスペースインベーダーのゲームプレイ
- 5種類の異なるインベーダー
- レベルシステム（難易度が徐々に上昇）
- スコアシステム
- ライフシステム（3ライフ）
- レトロな見た目とサウンド

## 🕹️ 操作方法

- **← → 矢印キー**: プレイヤーの移動
- **スペースキー**: 弾丸の発射
- **Enterキー**: ゲーム開始/再開

## 🎯 ゲームルール

1. 画面上部から降りてくるインベーダーを全て倒す
2. インベーダーの弾丸に当たらないように避ける
3. インベーダーが画面下部に到達するとゲームオーバー
4. 全てのインベーダーを倒すと次のレベルへ進む
5. レベルが上がるとインベーダーの速度が増加

## 📊 スコアシステム

- 上の列のインベーダー: 50点
- 2列目: 40点
- 3列目: 30点
- 4列目: 20点
- 下の列: 10点

## 🚀 起動方法

1. `index.html` をWebブラウザで開く
2. 「ゲーム開始」ボタンをクリックまたはEnterキーを押す
3. ゲームを楽しむ！
