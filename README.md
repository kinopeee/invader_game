# 🌟 ド派手インベーダーゲーム 🌟

壮大なビジュアルエフェクトと多彩な機能を持つ、現代的なスペースインベーダーゲームです！

## 🎮 ゲームの特徴

### 基本機能
- **美しいビジュアルエフェクト**: グロー効果、パーティクル、爆発エフェクト
- **サウンドエフェクト**: Web Audio APIによる動的なサウンド生成
- **レスポンシブデザイン**: PCとモバイルの両方に対応

### 新機能

#### 🔫 パワーアップシステム
3種類のパワーアップがランダムに出現します：
- **R（速射）**: 発射速度が3倍に！
- **3（3方向弾）**: 3方向に弾を発射！
- **S（シールド）**: 1回まで敵の攻撃を防ぐ！

#### ⚡ コンボシステム
- 連続で敵を倒すとコンボが増加
- 5体倒すごとにスコア倍率がアップ（最大5倍）
- 2秒以内に次の敵を倒さないとコンボリセット

#### 👾 ボス戦
- 5レベルごとに強力なボスが出現
- ボスは5方向に弾を発射
- 体力50の強敵！倒すと500ポイント

#### 🎯 難易度選択
- **イージー**: 残機5、敵の速度0.7倍
- **ノーマル**: 残機3、敵の速度1倍
- **ハード**: 残機2、敵の速度1.5倍

#### 🤖 特殊な敵
- **通常敵（灰色）**: 10ポイント
- **ジグザグ敵（マゼンタ）**: ジグザグに動く、20ポイント
- **高速敵（シアン）**: 1.5倍の速度で動く、15ポイント
- **タンク敵（オレンジ）**: 体力3、発射頻度2倍、30ポイント

#### 🏆 ハイスコアシステム
- 自動的にハイスコアを記録
- ゲームオーバー時に新記録達成を表示

#### 📱 モバイル対応
- タッチコントロールボタン
- タップでゲームスタート
- レスポンシブデザイン

## 🎲 操作方法

### PC
- **← →キー**: 左右に移動
- **スペースキー**: 弾を発射
- **スペースキー（スタート画面）**: ゲーム開始

### モバイル
- **← → ボタン**: 左右に移動
- **発射ボタン**: 弾を発射
- **画面タップ**: ゲーム開始

## 🚀 遊び方

1. 難易度を選択
2. スペースキーまたはタップでゲーム開始
3. 敵を全滅させてレベルアップ
4. パワーアップアイテムを取得して有利に進める
5. コンボを繋げてハイスコアを目指せ！
6. 5レベルごとのボス戦を突破しよう

## 💡 攻略のコツ

- パワーアップを積極的に取ろう！
- コンボを維持して高得点を狙おう
- 特殊な敵を優先的に狙うと効率的
- ボス戦では左右に動きながら弾を避けよう
- シールドは敵の弾が多いときの保険として活用

## 🛠️ 技術スタック

- **HTML5 Canvas**: ゲームレンダリング

- **CSS3**: スタイリングとアニメーション
